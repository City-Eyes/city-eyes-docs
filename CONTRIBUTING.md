# Contribuir com a documentação CITY EYES

Consulte a issue, critérios, estado de decisão e [Project único](https://github.com/orgs/City-Eyes/projects/1). O repositório de código é https://github.com/City-Eyes/city-eyes-code.

Commits e PRs seguem `tipo(escopo): resumo`, linha em branco e corpo explicando o porquê. Abra PR com `Closes #N` ou `Closes City-Eyes/city-eyes-code#N`; use `sem-issue` só para exceção aprovada. Aguarde CI até concluir.

Ao documentar pesquisa, prefira fonte primária, URL, data de publicação/consulta e limitações observadas. Não copie páginas integrais ou anexos para este repositório sem licença de redistribuição confirmada. Não transforme proposta em decisão aprovada.

Validação: `python3 scripts/validate-docs.py`. Atualize o plano canônico e os links de rastreabilidade quando uma decisão mudar.
