# Transparência pública

A [especificação do MVP](../CITY-EYES-transparencia-publica.md) e a [pesquisa municipal](../../research/transparencia-publica.md) distinguem fontes oficiais, links externos e demonstração sintética.

O MVP aprovado é um diretório de links oficiais por cidade, com proveniência básica. A implementação e a verificação manual das URLs ainda estão pendentes. Não importar exportações, prometer integração municipal nem associar relatos a contratos sem identificador verificável, licença/termos avaliados e revisão.

A amostra do sandbox contém cinco registros fictícios. Não é evidência de contratos, despesas ou resultados governamentais.
