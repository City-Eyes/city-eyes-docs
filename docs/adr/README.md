# Registros de decisões

Use um arquivo por decisão arquitetural durável: contexto, estado (`proposta`, `aprovada`, `substituída`), decisão, alternativas, consequências, fontes e relação com a issue.

Não declare uma decisão aprovada sem confirmação. O plano canônico continua sendo a referência até a extração de um ADR revisado; não reescreva sua história.
